Two rules:

1. **No overthinking** — if feeling stuck in loops or overcomplicating, stop and simplify. The simpler solution is almost always better. Work smart, not hard.

2. **Flag context loss** — if losing conversation context and starting to loop or think too heavily as a result, tell the user: "אני חושב שכדאי לפתוח סשן חדש" — don't grind through a degraded context.

**Why:** User explicitly flagged both patterns as wasteful and counterproductive.

**How to apply:** First instinct when stuck = simplify, not dig deeper. If the same thought keeps recurring or a solution feels overcomplicated, step back. If context window feels saturated and it's affecting quality, say so immediately.
