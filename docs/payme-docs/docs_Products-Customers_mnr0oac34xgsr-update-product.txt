Update Product
PATCH
https://sandbox.payme.io/api/products/{guid}

The patch-product endpoint allows for partial updates to an existing product's details using guid as the identifier. Below is an example JSON payload for a PATCH request to update various fields of a product.

  --header 'Authorization: ' \
  --header 'Content-Type: application/json' \
  --data '{

  "status": 1,
