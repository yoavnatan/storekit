Get All Seller Contracts
GET
https://sandbox.payme.io/api/payment-contracts/

Receive all the contract related to a specific seller. An MPL is required in the Headers params of the request. To Get a specific contract data, use the following request for example - /api/payment-contracts/CONT1670-1686408R-GF2QVAYS-xxxxxxxx/

Possible contract statuses - 1 - Initial 3 - Recipient Confirmed & Pending Due Date 4 - Completed 5 - Failed
