# https://payme.stoplight.io/docs/payments/85c316808c4c3-list-past-withdrawals

List Past Withdrawals
POST
https://sandbox.payme.io/api/get-withdrawals
Overview

You can retreive data on withdrawals requested by your sellers using this endpoint.

Query pagination (more than 500 results)

If you are sending a query and expect to receive more than 500 results, make sure you use this function of Query Pagination.

{
  "seller_payme_id": "MPL1DEMO-XXXXXXXX-XXXXXXXX-XXXXXXXX",
  ...
  "page_size": 100, // Max allowed page size is 500
  "page": 1
}

Send API Request
Staging
Request Sample: Shell / cURL
curl --request POST \
  --url https://sandbox.payme.io/api/get-withdrawals \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
  "payme_client_key": "partner-key",
  "items_order_by_column": "withdrawal_created",
  "items_order_by_direction": "desc",
  "seller_payme_id": "MPL1DEMO-XXXXXXXX-XXXXXXXX-XXXXXXXX",
  "page_size": 500,
  "page": 1,
  "withdrawal_created_min": "2021-06-01 00:00:00",
  "withdrawal_created_max": "2021-06-29 23:59:59",
  "language": "en"
}'
