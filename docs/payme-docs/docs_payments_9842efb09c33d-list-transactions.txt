# https://payme.stoplight.io/docs/payments/9842efb09c33d-list-transactions

List Transactions
POST
https://sandbox.payme.io/api/get-transactions
Overview

You can retreive data on different transactions processed by your sellers using this endpoint.

Filtering

In order to filter by transaction type, use the following method:

PARAMETER NAME	DESCRIPTION
transaction_status	The applicable transaction statuses.

You can find the transaction statuses in the following guide - Transaction Statuses.

Query pagination (more than 500 results)

If you are sending a query and expect to receive more than 500 results, make sure you use this function of Query Pagination.

{
  "seller_payme_id": "MPL1DEMO-XXXXXXXX-XXXXXXXX-XXXXXXXX",
  ...
  "page_size": 100, // Max allowed page size is 500
  "page": 1
}
