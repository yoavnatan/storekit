Get Recipient
GET
https://sandbox.payme.io/api/payment-contracts/recipients

That endpoint will return recipients that were already paid by the payment contract initiator.

**Only recipients that received the payment will return in the response. If the recipient doesn't approve the payment, his data won't return.
