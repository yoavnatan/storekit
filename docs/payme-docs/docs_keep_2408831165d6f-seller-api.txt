PayMe Seller API for income document creation using the new invoicing service.

Overview

This API allows sellers to create and manage income documents (invoices, receipts, etc.) using the new invoicing service.

Document Types
TYPE	DESCRIPTION
invoice	Invoice document
receipt	Receipt document
invrec	Invoice + Receipt combined
deal	Deal invoice
refund	Refund/Credit note
offer	Price quote/Offer
Supported Currencies

Currently only ILS (Israeli Shekel) is supported.

Document Languages
he - Hebrew
en - English
