# https://payme.stoplight.io/docs/payments/19af9dff1b4e1-list-subscriptions

List Subscriptions
POST
https://sandbox.payme.io/api/get-subscriptions
Overview

You can retreive data on subscriptions processed by your sellers using this endpoint.

To understand the different use-cases for this API, See Get Subscriptions API guide here.

Subscription Iteration Types

You can find them in the following guide - Subscription Iteration Types.

Subscription Statuses

You can find them in the following guide - Subscription Statuses.

Query pagination (more than 500 results)

If you are sending a query and expect to receive more than 500 results, make sure you use this function of Query Pagination.

{
  "seller_payme_id": "MPL1DEMO-XXXXXXXX-XXXXXXXX-XXXXXXXX",
  ...
  "page_size": 100, // Max allowed page size is 500
  "page": 1
}
