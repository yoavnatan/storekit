Get Contract Related Files
GET
https://sandbox.payme.io/api/payment-contracts/CONT{GUID}/invoices/

Allows receiving all files that are stored connected to a specific contract. We can use it to receive all files connected to a contract or just a specific file. To filter by various file types, we will use the following URL to receive the relevant file type - /CONT{GUID}/invoices?=Invoice Receipt
