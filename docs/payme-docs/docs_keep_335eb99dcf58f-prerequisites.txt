Prerequisites

Partner authorization layer protects the Partner's data on the Keep domain against unauthorized access and mutation.

The Keep API uses API keys to authenticate requests. Before starting integration you must receive your Partner API keys from your Account Manager:

Client ID
Client Secret

Your API keys carry many privileges, so be sure to keep them secure! Do not share your secret API keys in publicly accessible areas such as GitHub, client-side code, and so forth. The API keys must be provided during any interactions via OAuth2 Access and Refresh Tokens endpoint.

All API requests must be made over HTTPS. Calls made over plain HTTP will fail. API requests without authentication will also fail.
