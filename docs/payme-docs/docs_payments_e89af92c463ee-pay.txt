Overview

Relevant only for Direct API Integration

This endpoint is used to pay subscriptions. You can find more information in our guide - How to create a subscription .

Staging
Request Sample: Shell / cURL

  --url https://sandbox.payme.io/api/pay-subscription \
  --header 'Accept: application/json, application/xml, multipart/form-data, text/html, text/plain, application/EDI-X12, application/EDIFACT' \
  --header 'Content-Type: application/json' \
  --data '{
  "sub_payme_id": "SUB16885-68336QPL-UQSSS1CC-SYKXI53N",
  "credit_card_number": "4580458045804580",
  "credit_card_cvv": "123",

  "buyer_name": "John Doe"
}'
