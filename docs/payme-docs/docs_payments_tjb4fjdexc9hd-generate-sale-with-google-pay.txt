Generate Sale with Google Pay
POST
https://sandbox.payme.io/api/generate-sale
Overview

In order to initiate the process of paying using Google Pay APM, you will first need to initiate a generate-sale request to our API.

The request shall include "google-pay" as the sale_payment_method.

Send API Request
Sandbox
Request Sample: Shell / cURL
curl --request POST \
  --url https://sandbox.payme.io/api/generate-sale \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --data '{
  "seller_payme_id": "MPLDEMO-MPLDEMO-MPLDEMO-1234567",
  "sale_price": "1000",
  "currency": "ILS",
  "product_name": "T-Shirt",
  "language": "he",
  "sale_payment_method": "google-pay",
  "sale_type": "sale"
}'
