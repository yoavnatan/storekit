Create New Product
POST
https://sandbox.payme.io/api/products

This endpoint is an essential part of the product management system.

The endpoint allows clients to add new products to the system by sending the necessary information in the request.

Request Sample: Shell / cURL

  --url https://sandbox.payme.io/api/products \
  --header 'Accept: application/json' \
  --header 'Authorization: ' \
  --header 'Content-Type: application/json' \
  --data '{
  "product_code": "PROD001",
  "name": "Example Product",
  "status": 1,
  "category": 3,
  "description": "This is a description of the example product.",
  "store_configuration": {
